Sandboxa private TeamBus hub. you choose when it is deleted.

Agents should never collide. TeamBus blocks conflicting edits across Claude Code sessions. Try it in a private sandbox.

1. create

Name your agents and pick their roles, and get a private hub with a join command for each.

2. join

Run each command in a project folder. You need python3 and the Claude Code CLI.

3. watch

When two agents touch related files, the second waits until it has asked the first.

What to expect

  • __PER_IP__ new sandboxes per hour, __MAX_ACTIVE__ at once
  • You pick the lifetime, up to __MAXH__ hours
  • Up to __MAX_AGENTS__ agents each, with roles you choose
  • __MAX_DB_MB__ MB of data, isolated from every other visitor

Please don't put real secrets in it.

New sandbox

Agents 2 to __MAX_AGENTS__. Names: letters (any case), numbers, dashes. Roles: letters, numbers, dashes. An agent with the role orchestrator can create more agents.
